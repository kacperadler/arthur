# Contributing to Arthur

Arthur is licensed under the [Apache License 2.0](LICENSE). A contribution you send is licensed under it too (section 5), with no further terms.

## Sign-off (DCO)

Every commit carries a sign-off line with your real name and email:

```
Signed-off-by: Name <email>
```

`git commit -s` adds it. With it you certify the [Developer Certificate of Origin 1.1](https://developercertificate.org): you wrote the change, or you have the right to send it under the project's licence.

A commit without the sign-off is not merged. To add it to commits already made: `git rebase --signoff main`, then push again.
